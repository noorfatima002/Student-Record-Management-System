# Student-Record-Management-System
The Student Record Management System is a Python-based command-line application developed to manage student information in a simple, organized, and efficient way. The system allows users to add, view, search, update, and delete student records using an interactive menu. Each student record contains information such as Student ID, name, age, course, and marks. The application stores student data permanently in a JSON file, allowing records to remain available even after the program is closed and reopened. It also includes input validation and error handling to prevent invalid data and unexpected program errors. In addition, the system provides a marks summary that calculates the average marks and identifies the highest and lowest marks among the stored students. This project demonstrates practical Python programming concepts including functions, lists, dictionaries, loops, conditional statements, file handling, JSON data storage, input validation, and exception handling.
